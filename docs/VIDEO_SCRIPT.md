## 视频录制快捷指南 (基于本机 OBS Studio)

1. **启动服务**：
   - 双击根目录下刚刚创建的 `start-windows.bat`（或在 Mac 上运行 `./start-mac.sh`）；
   - 浏览器将自动打开 `http://localhost:5173`。
2. **打开 OBS Studio**：
   - 启动 OBS（位于 `E:\Application\obs-studio\bin\64bit\obs64.exe`）；
   - 添加「窗口采集」或「显示器采集」，目标为浏览器窗口（建议分辨率设为 1920×1080）；
   - 音频采集：选择您的麦克风或录屏后叠加 TTS 音频。
3. **录制实操动作（约 2 分钟）**：
   - 按照上方表格中 5 个画面的操作，依次点击「演示攻击拦截」→「新建任务并审批」→「紧急停止」→ 终端运行示例客户端。
4. **导出文件**：
   - 将导出的 MP4 文件命名为 `Agent_Guard_Demo_1080p.mp4`，存入 `docs/` 或提交压缩包中即可！
